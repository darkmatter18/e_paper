# Darshan - Branding Guide

## Name
**Darshan** (दर्शन)

**Meaning**: Vision, sight, divine glimpse - in Hindu tradition, darshan means having a blessed view or auspicious viewing of a deity or sacred object.

## Tagline
**"A sacred glimpse"**

## Logo/Icon
- **File**: `static/darshan-icon.svg`
- **Design**: Minimalist third eye/vision symbol
  - Outer circle (cosmic boundary)
  - Inner vertical ellipse (eye shape)
  - Center dot (bindu/focal point)
  - Top arc (tilak/third eye marking)
- **Style**: Single-color line art, adapts to text color (currentColor)
- **Usage**: 
  - Favicon: 32x32px
  - Header logo: 28px height
  - Scales cleanly as SVG

## Color Palette
- **Primary**: `#667eea` to `#764ba2` (purple gradient)
- **Secondary**: `#f8f9fa` (light gray backgrounds)
- **Accent**: `#155724` (success green), `#721c24` (error red)
- **Text**: `#333` (dark gray), `#666` (medium gray)

## Typography
- **Font**: System fonts (-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, etc.)
- **Headings**: 600 weight (semi-bold)
- **Body**: 400 weight (regular)

## Voice & Tone
- **Spiritual**: References to sacred, blessed, divine
- **Minimalist**: Clean, simple, uncluttered
- **Peaceful**: Zen-like, serene, contemplative
- **Informative**: Clear, helpful, present

## API Branding
- **Title**: "Darshan API"
- **Description**: "A sacred glimpse - Control display screens via REST API"
- **Version**: 1.0.0
- **Base URL**: `http://localhost:8000` (default)

## UI Components
- **Title**: "Darshan" with logo icon
- **Subtitle**: "A sacred glimpse"
- **Footer**: "Darshan v1.0.0"
- **Page Titles**: 
  - Main: "Darshan"
  - Login: "Login - Darshan"

## Philosophy
Darshan represents the act of seeing with intention and reverence. The e-paper display provides a "sacred glimpse" of what matters - time, weather, memories (photos), and peaceful imagery. The interface is designed to be contemplative and unobtrusive, like receiving darshan in a temple.
